- (constraint) Architecture AD-10: apps/web SPA is a view over the API (no domain computation client-side; types generated from OpenAPI); packages/ui (@locker/ui) is presentation-only shadcn/Tailwind — no fetching, no business logic
- (constraint) PRD section 6 fixes two surfaces: Delivery Agent console (create lockers, view station, store package -> locker+pickup code) and Customer view (retrieve with charge breakdown or clear errors); component library ships product components LockerGrid, LockerCard, StorePackageForm, RetrievePackageForm, ChargeSummary
- (decision) Foundation UI system = shadcn/ui on Tailwind CSS 4 (React 19, Vite SPA); DESIGN.md specifies the brand-layer delta over shadcn defaults like the shadcn example pattern
- (decision) Inputs confirmed by user: docs/prd.md + docs/design/source-theme.md + ARCHITECTURE-SPINE.md (AD-10 + endpoint/error contracts shape UI states)
- (decision) Working mode: coaching path
- (decision) Form factor: one responsive SPA — agent console desktop-lean, customer retrieval phone-first (customer holds phone at the locker)
- (decision) Theming: dark AND light modes — dark is the default (faithful to the Everest deck), light mode included as a full theme; brand tokens (orange #F5A100, butter-yellow, cream) carry across both
- (decision) Pickup-code entry: code-style chunked input (XXXX-XXXX grouping), alphabet excludes 0/O/1/I by design so the confusing keys never appear; mobile-friendly large targets
- (decision) Motion: subtle transitions only — restrained fades/slides (150-250ms), preserves the matte editorial stillness of the deck; no bounces, no parallax
- (decision) Journey protagonists adopted: Rahul (gig courier, 40 stops, tablet in van; climax = assigned locker ID + pickup code displayed large and unambiguous, he photographs the screen; wrinkle = no suitable locker for LARGE -> instant calm rejection) and Meera (customer at station, phone in one hand, toddler on hip, 12% battery; climax = charge breakdown understood before commit; wrinkle = fat-fingered code once -> blame-free error, input preserved, one-tap retry)
- (decision) IA closed: chooser landing at / (two role cards, Everest-branded); agent console at /agent (station view + store panel + create locker); customer retrieval at /retrieve (direct URL, QR-code friendly); every PRD Section 6 need has a surface; no auth, no role toggle
- (decision) State matrix maps 1:1 to AD-7 error codes with human copy: NO_SUITABLE_LOCKER=calm actionable capacity message; INVALID_PICKUP_CODE=blame-free, input preserved, one-tap retry; LOCKER_NOT_FOUND=check-the-ID hint; LOCKER_EMPTY=already-picked-up explanation; VALIDATION_ERROR=inline field messages; INTERNAL_ERROR=our-side apology + retry, never raw dump; plus empty-station first-run moment (agent) and skeleton loading states
- (decision) Interaction patterns: pickup-code input XXXX-XXXX chunked, auto-advance, auto-uppercase, paste-tolerant; one-tap copy on pickup code + locker ID; errors never clear user input; station grid updates immediately after successful store
- (decision) Station grid live availability: auto-refresh polling every ~10s while grid visible (user chose; also demos Level-4 concurrency live), manual refresh still available
- (decision) Typography: display = DM Serif Display (Google Fonts, Didone class) for ALL-CAPS page titles; body/label = Inter (shadcn-native, matches deck's Inter-class body); mono for codes = ui-monospace stack
- (decision) Token mapping onto shadcn defaults: dark default (bg #0D0D0B, card #141414, border #2A2A2A, primary #F5A100, highlight #F5EFB8 display text, cream #E8D9A8 locker tiles, fg #F5F2EC, muted #8A8A8A); light theme = warm paper bg #F5F2EC, card #FBF9F3, border #E5DFD2, fg #1A1915, primary #F5A100 with ink-black button text (~9:1 contrast, black-on-orange is in the deck's own logo), highlight/cream become tint washes with dark text
